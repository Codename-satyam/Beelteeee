A stripped-back tournament setup

Enter the fog.Own the match.

A stripped-back tournament toolkit using plain HTML, CSS, JavaScript and local JSON. Manage a bracket, vote on the map, allocate points and show the live scoreboard in real time between two streamers.

Open tournament control →Preview live screenBracket screen
01 // BROADCAST

Live Scoreboard

Large team names, live points, round status, toss details and recent results. Add ?overlay=1 for a compact OBS-style overlay.
02 // MAP VOTE

Toss & Map Voting

Flip a coin to determine who bans first, then alternate map bans until one realm remains.
03 // MATCH OPS

Bracket & Point Allocation

Build the tournament bracket, assign in-game points, complete matches and automatically advance winners.
Storage note: map names load from data/maps.json (a built-in list is used if it is missing). With Supabase configured in shared/supabase-config.js, both streamers sign in on the control pages and every change syncs live to all screens. Without it, state stays in this browser; use Export/Import State JSON to move it.
